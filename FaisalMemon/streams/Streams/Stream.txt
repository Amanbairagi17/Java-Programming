What is Stream in Java?
A Stream in Java (from java.util.stream) is a sequence of elements (like from a Collection or array) that supports functional-style
 operations such as filtering, mapping, and reducing — without changing the original data.
Think of it as a data flow — you process elements in a pipeline instead of using loops.

List<Integer> numbers = List.of(1, 2, 3, 4, 5);
numbers.stream()
       .filter(n -> n % 2 == 0)   // keep even numbers
       .map(n -> n * n)           // square them
       .forEach(System.out::println); // print
output : 4 16


Stream Pipeline:
A Stream Pipeline is a chain of stream operations consisting of:
Source
Intermediate Operations
Terminal Operation

1. Source
Where the stream starts (e.g., Collection, array, file, etc.)
numbers.stream()

2. Intermediate Operations
Transform or filter data (return another Stream).
Lazy — executed only when terminal operation runs.
Examples: filter(), map(), sorted(), distinct(), limit()
.filter(n -> n > 2)
.map(n -> n * 2)

3. Terminal Operation
Produces a result or side effect (ends the pipeline).
Examples: forEach(), collect(), count(), reduce()
.forEach(System.out::println);

Source → Intermediate → Terminal
Eg.:
List<Integer> result = numbers.stream()
                              .filter(n -> n % 2 == 0)
                              .map(n -> n * 2)
                              .toList();


Key Points:
Streams don’t store data — they operate on existing data sources.
Operations are functional and chainable.
Intermediate ops are lazy, terminal ops are eager.
Supports parallel processing via .parallelStream().
